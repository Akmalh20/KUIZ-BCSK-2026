📖 Langkah Demi Langkah Menyambungkan Kuiz ke Google Sheets

Langkah 1: Cipta Google Sheet Baharu

  1. Buka Google Sheets (sheets.new).
  2. Namakan fail sebagai: Penyertaan Minggu Bahasa Cina SK Subang Jaya.

Langkah 2: Buka Apps Script Editor

Di Google Sheet tadi, klik menu atas: Extensions (Sambungan) > Apps Script.

Padam semua kod sedia ada, dan salin (Copy & Paste) kod Google Apps Script di bawah:

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  
  try {
    var doc = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = doc.getActiveSheet();
    
    // Sokong data sama ada dari Form Data (parameter) atau JSON postData
    var data = {};
    if (e.parameter && e.parameter.name) {
      data = e.parameter;
    } else if (e.postData && e.postData.contents) {
      data = JSON.parse(e.postData.contents);
    }
    
    var name = (data.name || "").toString().trim();
    if (!name) {
      return ContentService.createTextOutput(JSON.stringify({ status: "error", message: "Tiada nama" }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    
    // Semak jika nama sudah pernah menjawab (Syarat 1 Kali Sahaja)
    var allRows = sheet.getDataRange().getValues();
    var hasAnswered = false;
    for (var i = 1; i < allRows.length; i++) {
      if (allRows[i][1] && allRows[i][1].toString().trim().toLowerCase() === name.toLowerCase()) {
        hasAnswered = true;
        break;
      }
    }
    
    if (hasAnswered) {
      return ContentService.createTextOutput(JSON.stringify({
        status: "duplicate",
        message: "Percubaan pertama sahaja diambil kira."
      })).setMimeType(ContentService.MimeType.JSON);
    }
    
    // Catat data murid ke Google Sheet
    sheet.appendRow([
      new Date(),
      name,
      data.role || "-",
      data.className || "-",
      Number(data.score) || 0,
      Number(data.timeSeconds) || 0,
      data.timeFormatted || "00:00"
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success", message: "Data berjaya direkod!" }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}

function doGet(e) {
  var doc = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = doc.getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var records = [];
  
  for (var i = 1; i < rows.length; i++) {
    if (rows[i][1]) {
      records.push({
        timestamp: rows[i][0],
        name: rows[i][1],
        role: rows[i][2],
        className: rows[i][3],
        score: Number(rows[i][4]),
        timeSeconds: Number(rows[i][5]),
        timeFormatted: rows[i][6]
      });
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify(records))
    .setMimeType(ContentService.MimeType.JSON);
}

Langkah 3: Deploy (Gunakan Sebagai Web App)

  1. Klik butang biru Deploy (Gunakan) > New deployment (Guna baharu) di bucu atas Apps Script.
  2. Pilih gear jenis: Web app.
  3. Tetapan penting:
    • Execute as (Jalankan sebagai): Me (Akaun Google Anda)
    • Who has access (Siapa yang boleh akses): Anyone (Sesiapa sahaja) ← Wajib pilih ini supaya murid tidak perlukan akaun Google untuk menghantar markah!
  4. Klik Deploy, benarkan 'Authorize Access' dengan akaun Google anda.
  5. Salin Web App URL yang diberikan (bermula dengan https://script.google.com/.../exec).
  6. Tampal URL tersebut di dalam kotak hijau di atas tab ini dan klik Simpan URL!
